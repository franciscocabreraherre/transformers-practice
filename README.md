# Description for transformers-practice
It's just a personal repo to store my notebooks as I teach myself more about transformers in general.

This README and repository will both be in English because it's just for personal use and it's more practical for me than working in Spanish or French, so if by some random chance you found your way here and want to use or read the code you know what to expect.  

## How to use  

Content is sorted by level based on the course by the LazyProgrammer / DeepLearningCourses, just grab the notebook and run things in Colab. Datasets are stored directly on collab and obtained on runtime via APIs or `!wget`.
